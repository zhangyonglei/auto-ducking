# AutoDucking

macOS 菜单栏音频闪避工具。麦克风被任何 App 占用时，自动把系统输出音量降到指定比例；麦克风释放后，等待一小段时间再平滑恢复。

只监测麦克风**是否被占用**，不录音、不读取音频内容，也不需要麦克风权限。

## 功能

- 菜单栏常驻，图标随状态变化（待命 / 闪避中 / 已关闭）。
- 麦克风被占用时按原音量比例闪避，结束后恢复原音量。
- 闪避幅度、淡入时长、淡出时长、恢复延迟均可调。
- 内置五种预设：语音输入、标准、会议通话、深度录音、轻柔。
- 可设置登录时自动启动。
- 原生 macOS 设置窗口、关于窗口与版本更新日志。
- 事件驱动，空闲时不轮询；渐变由 60Hz 定时器驱动，仅持续数百毫秒。

## 系统要求

macOS 14 或更高版本。支持 Apple Silicon 与 Intel。

## 构建与运行

```bash
./scripts/build.sh --open
```

产物位于 `build/AutoDucking.app`。也可以直接运行调试：

```bash
swift run AutoDucking
```

安装到「应用程序」目录：

```bash
cp -R build/AutoDucking.app /Applications/
```

> 首次从本地构建运行时，macOS 可能提示确认打开。应用使用 ad-hoc 签名，不包含公证。

## 使用

1. 启动后应用只出现在菜单栏，没有 Dock 图标。
2. 点击菜单栏麦克风图标，可以启用/关闭闪避、切换预设、测试闪避效果。
3. 打开「设置…」调整闪避幅度与过渡参数。
4. 播放音乐，然后打开任意使用麦克风的应用（语音输入、听写、会议、录音），音量会自动降低；麦克风释放后按恢复延迟平滑恢复。

闪避后的目标音量是「当前输出音量的百分比」，因此不会把背景声放大。例如当前音量 50%、闪避比例 30%，闪避后为 15%。

## 预设

| 预设 | 闪避后 | 淡入 | 淡出 | 恢复延迟 |
| --- | --- | --- | --- | --- |
| 语音输入 | 15% | 0.10s | 0.35s | 0.20s |
| 标准 | 30% | 0.20s | 0.50s | 0.80s |
| 会议通话 | 20% | 0.15s | 0.40s | 0.50s |
| 深度录音 | 8% | 0.30s | 0.60s | 1.50s |
| 轻柔 | 55% | 0.35s | 0.80s | 1.20s |

手动调整任一参数后，预设会显示为自定义状态。

## 版本号与更新日志

- 版本号保存在 `VERSION`，构建号来自构建时间。
- 在 `CHANGELOG.md` 的 `## [未发布]` 下添加条目，下次构建会自动升一位补丁版本并写入日期。
- 需要升次版本或主版本时：

```bash
./scripts/bump-version.sh minor
./scripts/bump-version.sh major
```

版本与更新日志显示在菜单栏「关于 AutoDucking」窗口。

## 图标

图标由 `scripts/generate-icon.swift` 使用 AppKit 绘制（渐变圆角底、白色麦克风与递减音量条），并生成完整 iconset 与 `.icns`：

```bash
swift scripts/generate-icon.swift
```

构建脚本会在图标缺失或绘制脚本更新时自动重新生成。

## 实现要点

- **麦克风检测**：监听所有输入设备的 `kAudioDevicePropertyDeviceIsRunningSomewhere`，任一设备被占用即视为麦克风开启；设备增删会动态重建监听，无需轮询。
- **音量控制**：通过 CoreAudio HAL 读写默认输出设备的 `kAudioDevicePropertyVolumeScalar`，兼容仅支持声道音量的设备。
- **闪避引擎**：状态机记录闪避前的基准音量，淡入/淡出使用 smoothstep 插值；输出设备切换时先恢复旧设备，再对新设备闪避。
- **数据安全**：不创建音频采集流，不申请麦克风权限，不写入任何音频数据。
